## Architecture Overview

This is a **static HTML/CSS/JS** website with no build step. Components are loaded via `<script>` tags and render dynamically using DOM manipulation.

### Key Principles

- **No framework required** — vanilla JS with ES6+ features
- **Modular CSS** — files are loaded directly via `<link>` tags (not `@import`)
- **Dynamic components** — navbar & footer are generated by JS and injected into placeholder elements
- **Theme-aware** — all components support dark/light modes via CSS variables

### File Loading Order

Each HTML page loads assets in this order:

```
1. CSS: vendor/bootstrap.min.css
2. CSS: base/variables.css → base/theme.css → base/reset.css → base/typography.css
3. CSS: layouts/sections.css
4. CSS: components/ (navbar, footer, buttons, cards, hero, etc.)
5. CSS: main.css (global utilities, animations, forms)
6. CSS: styles.css (additional/legacy styles)
7. CSS: pages/<page-specific>.css (if applicable)
8. JS:  vendor/bootstrap.bundle.min.js
9. JS:  components/ (navbar.js, footer.js, preloader.js, feedback.js)
10. JS: utils/ (theme.js, animations.js, helpers.js)
11. JS: pages/<page-specific>.js (if applicable)
12. JS: main.js (App controller — initializes everything)
```

## Component System

### Dynamic Header (`navbar.js`)

The header is rendered dynamically from JavaScript. It detects the current page and applies the active state.

**Usage in HTML:**
```html
<header data-navbar data-base-path="./" data-current-page="home"></header>
```

**Data Attributes:**

| Attribute | Description | Example Values |
|-----------|-------------|----------------|
| `data-navbar` | Marks element as navbar container | *(no value)* |
| `data-base-path` | Relative path to project root | `./`, `../`, `../../` |
| `data-current-page` | Page ID for active nav highlighting | `home`, `about`, `programs`, `admissions`, `campus-life`, `contact` |

**Available Page IDs:** `home`, `about`, `programs`, `admissions`, `campus-life`, `contact`

### Dynamic Footer (`footer.js`)

**Usage in HTML:**
```html
<div data-footer data-base-path="./"></div>
```

| Attribute | Description |
|-----------|-------------|
| `data-footer` | Marks element as footer container |
| `data-base-path` | Relative path to project root |

## Theme System

### How It Works

1. A `data-theme` attribute on `<html>` controls the active theme
2. CSS variables change values based on `[data-theme="light"]` selectors
3. The `ThemeManager` class in `theme.js` handles toggle, persistence, and smooth scroll
4. User preference is stored in `localStorage`
5. System preference (`prefers-color-scheme`) is respected as the default

**Toggle:** Sun/Moon button in the navbar

**Key Files:**
- `assets/css/base/theme.css` — theme variable overrides
- `assets/js/utils/theme.js` — ThemeManager class

### Theme Variables

**Dark Theme (default):**
```css
:root {
    --color-bg-primary: #0f172a;
    --color-bg-secondary: #1e293b;
    --color-text-primary: #ffffff;
    --color-accent-primary: #3b82f6;
}
```

**Light Theme:**
```css
[data-theme="light"] {
    --color-bg-primary: #ffffff;
    --color-bg-secondary: #f1f5f9;
    --color-text-primary: #0f172a;
}
```

### Adding Theme Support to a New Component

1. Write your dark-mode styles normally using CSS variables
2. Add light-mode overrides in `theme.css`:

```css
[data-theme="light"] .your-component {
    background: var(--color-bg-secondary);
    color: var(--color-text-primary);
}
```

> **Tip:** Use `!important` sparingly — only when the cascade can't be resolved otherwise.

## Animation System

### Scroll Animations (`animations.js`)

Add the `data-animate` attribute to any element to trigger entrance animations when scrolled into view:

```html
<div data-animate="fadeInUp" data-delay="200">
    Content animates in when visible
</div>
```

**Available Animations:**

| Animation | Effect |
|-----------|--------|
| `fadeIn` | Opacity 0 → 1 |
| `fadeInUp` | Slide up + fade |
| `fadeInDown` | Slide down + fade |
| `fadeInLeft` | Slide from left + fade |
| `fadeInRight` | Slide from right + fade |
| `scaleIn` | Scale 0.9 → 1 + fade |

**CSS Animation Classes** (for direct use):
- `.animate-fade-in`, `.animate-fade-in-up`, `.animate-scale-in`, etc.
- `.animate-pulse` — infinite pulsing
- `.animate-float` — infinite floating
- Delays: `.delay-100` through `.delay-500`

**Initial State:** Elements with `[data-animate]` start with `opacity: 0` and gain `.animated` class when triggered.

## Adding New Pages

### Step 1: Create HTML File

Create a new file in `pages/` (or `pages/departments/` for department pages).

### Step 2: Include Required Assets

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Page Title — GCT Bhakkar</title>

    <!-- Favicon -->
    <link rel="icon" href="../assets/favicon/favicon.png" type="image/png">

    <!-- Vendor CSS -->
    <link rel="stylesheet" href="../assets/css/vendor/bootstrap.min.css">
    <link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.5.0/css/all.min.css">
    <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap-icons@1.10.5/font/bootstrap-icons.css">

    <!-- Base CSS -->
    <link rel="stylesheet" href="../assets/css/base/variables.css">
    <link rel="stylesheet" href="../assets/css/base/theme.css">
    <link rel="stylesheet" href="../assets/css/base/reset.css">
    <link rel="stylesheet" href="../assets/css/base/typography.css">

    <!-- Layout & Components -->
    <link rel="stylesheet" href="../assets/css/layouts/sections.css">
    <link rel="stylesheet" href="../assets/css/components/navbar.css">
    <link rel="stylesheet" href="../assets/css/components/footer.css">
    <link rel="stylesheet" href="../assets/css/components/buttons.css">
    <link rel="stylesheet" href="../assets/css/components/cards.css">
    <link rel="stylesheet" href="../assets/css/components/hero.css">
    <link rel="stylesheet" href="../assets/css/components/preloader.css">
    <link rel="stylesheet" href="../assets/css/components/feedback.css">

    <!-- Global Styles -->
    <link rel="stylesheet" href="../assets/css/main.css">
    <link rel="stylesheet" href="../assets/css/styles.css">

    <!-- Page-specific CSS (optional) -->
    <!-- <link rel="stylesheet" href="../assets/css/pages/your-page.css"> -->
</head>
<body>

    <!-- Accessibility: Skip to content -->
    <a href="#main-content" class="skip-to-content">Skip to main content</a>

    <!-- Dynamic Header -->
    <header data-navbar data-base-path="../" data-current-page="your-page"></header>

    <!-- Main Content -->
    <main id="main-content">
        <section class="section">
            <div class="container">
                <div class="section-header">
                    <h2 class="section-title">Section Title</h2>
                    <p class="section-subtitle">Description text</p>
                </div>
                <!-- Content here -->
            </div>
        </section>
    </main>

    <!-- Dynamic Footer -->
    <div data-footer data-base-path="../"></div>

    <!-- Scripts -->
    <script src="../assets/js/vendor/bootstrap.bundle.min.js"></script>
    <script src="../assets/js/components/navbar.js"></script>
    <script src="../assets/js/components/footer.js"></script>
    <script src="../assets/js/components/preloader.js"></script>
    <script src="../assets/js/components/feedback.js"></script>
    <script src="../assets/js/utils/theme.js"></script>
    <script src="../assets/js/utils/animations.js"></script>
    <script src="../assets/js/utils/helpers.js"></script>
    <script src="../assets/js/main.js"></script>
</body>
</html>
```

|---------------|-------------------|--------------|
| `pages/*.html` | `../` | `../assets/...` |
| `pages/departments/*.html` | `../../` | `../../assets/...` |

## Feedback Component

The feedback system (`feedback.js` + `feedback.css`) auto-shows a modal to collect user ratings.

### Behavior
- **Time trigger:** Shows after 30 seconds (15s on mobile)
- **Scroll trigger:** Shows after user scrolls 60% (40% on mobile)
- **Snooze:** Dismissed modals reappear after 30 minutes
- **Persistence:** Uses `localStorage` to track submitted/snoozed state
- **Mobile:** Supports swipe-down-to-dismiss and haptic feedback

### API (available on `window.Feedback`)

```javascript
// Reset feedback state for testing
Feedback.reset();
```

## Video Player

The home page includes a custom video player for the campus video, defined in `main.js`.

### Features
- Play/pause with button or click
- Mute/unmute toggle
- Progress bar with seek
- Auto-play/pause on scroll (IntersectionObserver)
- Starts muted to comply with browser autoplay policies

### Required HTML IDs
- `campusVideo` — the `<video>` element
- `playPauseBtn` — play/pause button
- `muteBtn` — mute toggle button
- `videoProgress` — `<input type="range">` for seek
- `currentTime` / `duration` — time display elements

## Responsive Design

### Breakpoints

| Breakpoint | Max Width | Layout Change |
|------------|-----------|---------------|
| Large | `1200px` | 4-column → 2-column grids |
| Medium | `991px` | 2-column → 1-column |
| Small | `768px` | Mobile layout, scroll hints activate |
| X-Small | `576px` | Compact mobile styling |

### Mobile Enhancements (via `main.js`)

- **Scroll Hints:** `.mobile-scroll-row` containers get a gradient edge and arrow indicator on mobile
- **Infinite Marquee:** `.mobile-infinite-scroll` containers auto-scroll with touch-to-pause

## Common Customization Tasks

### Changing Brand Colors

Edit `assets/css/base/variables.css`:
```css
--color-accent-primary: #your-color;
--color-accent-secondary: #your-highlight;
```

Then update light-mode overrides in `assets/css/base/theme.css` if needed.

### Updating Navigation Links

Edit the navigation array in `assets/js/components/navbar.js`:
```javascript
getNavigation() {
    return [
        { name: 'Home', href: '...', id: 'home' },
        // Add or modify links here
    ];
}
```

### Updating Social / Footer Links

Edit the social links array in `assets/js/components/footer.js`.

### Adding a New Page to Navigation

1. Create the HTML page (see [Adding New Pages](#adding-new-pages))
2. Add entry to `navbar.js` navigation array
3. Optionally add to footer quick links in `footer.js`
